# 🛒 Shop App

A full-featured shopping application built with **React.js**, using publicly available data to fetch and display product information.

The application is currently **database-free** and works locally.

## 🛠️ Technologies

* React.js
* JavaScript
* Public API / Data source

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/PhilippesDev/Shop-app-.git
```

Navigate to the project:

```bash
cd Shop-app-
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 🗄️ Database

This project currently does not use a database.

Product data is retrieved from publicly available data.
